# Projeto Web: Exploração Astronômica & Cosmos

Este projeto é uma atividade prática desenvolvida para a disciplina de **Desenvolvimento Web**, com o objetivo principal de praticar **design responsivo** e a construção de interfaces modernas utilizando o framework **Bootstrap 5**.

O site é temático e aborda a história da astronomia, descobertas do Sistema Solar, grandes observatórios espaciais e a evolução da exploração do cosmos.

---

## Objetivos do Projeto

- **Prática de Responsividade:** Utilizar o sistema de grid (*flexbox grid*) e pontos de interrupção (*breakpoints*) do Bootstrap para garantir a adaptabilidade do layout em diferentes tamanhos de tela (smartphones, tablets e desktops).
- **Componentização e Frameworks:** Aplicar componentes nativos do Bootstrap (carrosséis, sanfonas/accordions, modais, formulários, tabelas e menus de navegação).
- **Estruturação Semântica:** Construção de páginas usando boas práticas de HTML5 e CSS3 personalizado.

---

## Estrutura das Páginas

O site conta com 5 páginas principais encadeadas no menu de navegação:

1. **`index.html` (Home):**
   - Apresentação da missão do projeto.
   - Carrossel de destaques com imagens do cosmos.
   - Accordion com informações detalhadas sobre o Sistema Solar, Missão Apollo, Telescópios Espaciais e Descobertas Recentes.

2. **`dados.html` (Dados e Estatísticas):**
   - Tabelas estilizadas com dados do Sistema Solar e comparativos de observatórios/telescópios.
   - Seção de Perguntas Frequentes (FAQ) usando o componente *Accordion Flush*.

3. **`galeria.html` (Linha do Tempo):**
   - Linha do tempo interativa apresentada através de cartões (*Cards*).
   - Uso de **Modais** (`Modal`) para exibição de detalhes históricos de cada era espacial.

4. **`sobre.html` (Sobre):**
   - Contextualização histórica da astronomia, desde as observações antigas até os avanços modernos.

5. **`contato.html` (Contato):**
   - Formulário responsivo com campos de validação básica (`input`, `select`, `radio buttons`, `checkboxes` e `textarea`).

---

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica das páginas.
- **CSS3:** Estilização global (`style.css`).
- **Bootstrap 5.3:** Layout responsivo, utilitários de espaçamento, cores e componentes JS.

---

## Como Executar o Projeto

1. Clone ou baixe os arquivos deste repositório.
2. Certifique-se de que a estrutura de pastas contém as imagens na pasta `/image` e o CSS na pasta `/css`.
3. Abra qualquer arquivo `.html` (recomendado: `index.html`) diretamente no seu navegador de preferência.
